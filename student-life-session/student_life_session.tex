\begin{frame}{How it works}
  \centering
  \Large
  Interest poll (Discord)
  $\rightarrow$

  $\rightarrow$
  Approval from MScAC Program Staff
  $\rightarrow$
  RSVP (Partiful Event)
  $\rightarrow$
  Host the event (Save the receipts!)
  $\rightarrow$
  Submit reimbursement request (4--6 week processing time)
